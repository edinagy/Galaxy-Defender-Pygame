# Cinematic audio sources

The selected `.ogg` files in this directory are from the following Kenney
asset packs:

- Sci-fi Sounds: https://kenney.nl/assets/sci-fi-sounds
- Digital Audio: https://kenney.nl/assets/digital-audio
- Interface Sounds: https://kenney.nl/assets/interface-sounds
- Impact Sounds: https://kenney.nl/assets/impact-sounds

Kenney publishes the assets on these pages under Creative Commons CC0. The
original license text is included in `KENNEY_CC0_LICENSE.txt`. Attribution is
not required, but the source is recorded here for release documentation.

Only the files used by `cinematic_audio.py` and `gameplay_audio.py` are
included in the game.
